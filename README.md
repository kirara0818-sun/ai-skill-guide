왕초보 AI 강의용 웹페이지입니다. 지금 상황과 닮은 카드를 고르면 **준비물 · 따라 하는 순서 · 실제 입력 예시 · 그대로 복사해서 쓰는 명령어 · 자주 막히는 부분**이 한 번에 열립니다.
정적 페이지라 서버가 필요 없고, GitHub Pages 주소로 누구에게나 그대로 보낼 수 있습니다.

| 순서 | 카테고리 | 항목 | 명령어 | 개별 공유 링크 |
| --- | --- | --- | --- | --- |
| 1 | 🎬 영상 만들기 | 13 | 19 | `?cat=video&only=1` |
| 2 | 📱 SNS 키우기 | 3 | 10 | `?cat=sns&only=1` |
| 3 | 🎨 디자인·PPT | 4 | 6 | `?cat=design&only=1` |
| 4 | ✍️ 글쓰기·블로그 | 3 | 5 | `?cat=writing&only=1` |
| 5 | 🌐 자료 조사 | 2 | 2 | `?cat=research&only=1` |
| 6 | 📚 공부·학습 | 2 | 2 | `?cat=study&only=1` |
| 7 | 🤖 AI 팀 만들기 | 6 | 7 | `?cat=team&only=1` |

- `?cat=video` — 그 카테고리가 선택된 채로 열립니다. (탭은 그대로 보입니다)
- `?cat=video&only=1` — **수강생 공유용.** 다른 탭과 검색 도움말이 숨고 그 카테고리만 깔끔하게 보입니다.
- 화면 위 **현재 카테고리 링크 복사** 버튼을 누르면 지금 보고 있는 카테고리의 `?cat=...&only=1` 링크가 복사됩니다.

## 폴더 구조

```
index.html              화면의 뼈대 (디자인)
styles.css              색·여백·카드·모달·탭 (디자인)
app.js                  검색·탭·필터·모달·복사·공유 링크 (동작)
data/categories.json    카테고리 7개 목록 (탭 이름·순서)
data/video.json         🎬 영상 만들기 항목
data/sns.json           📱 SNS 키우기 항목
data/design.json        🎨 디자인·PPT 항목
data/writing.json       ✍️ 글쓰기·블로그 항목
data/research.json      🌐 자료 조사 항목
data/study.json         📚 공부·학습 항목
data/team.json          🤖 AI 팀 만들기 항목
README.md               이 문서
```

디자인과 내용이 분리되어 있어서, **항목을 늘리거나 문장을 다듬을 때는 `data/*.json`만 고치면 됩니다.**
HTML·CSS·JS는 건드릴 필요가 없습니다.

## 클로드·GPT에게 항목 추가를 부탁하는 법 (3줄)

1. 고칠 카테고리의 파일(예: `data/video.json`)을 통째로 복사해 클로드나 GPT에게 붙여넣습니다.
2. 이어서 이렇게 말합니다: **"이 JSON 양식 그대로, 아래 내용으로 항목을 하나 더 추가해 줘. 기존 항목은 건드리지 말고 같은 키 이름·같은 순서로 유지해 줘. 결과는 JSON 코드블록 하나로만 줘."**
3. 받은 JSON으로 해당 파일을 통째로 바꿔 저장하고 GitHub에 올리면 1~2분 뒤 페이지에 반영됩니다.

## 카테고리 파일의 양식

```json
{
  "category": { "id": "video", "emoji": "🎬", "title": "영상 만들기", "nav": "영상 만들기",
                "lead": "카테고리 제목 아래 설명", "desc": "한 줄 소개" },
  "guide": { "title": "읽어 두면 좋아요", "blocks": [
    { "kind": "text", "text": "설명 문장" },
    { "kind": "table", "head": ["칸", "설명"], "rows": [["A", "첫째 줄"]] },
    { "kind": "note", "title": "상태 표기", "text": "대기 → 진행 중 → 완료" }
  ] },
  "filters": [
    { "id": "all", "label": "전체" },
    { "id": "shorts", "label": "쇼츠·릴스" }
  ],
  "items": [
    {
      "id": "auto-caption",
      "cat": "video",
      "filter": "shorts",
      "title": "영상 올려서 자막 넣기",
      "situation": "컷 편집과 자막만 빨리 끝내고 싶을 때",
      "summary": "편집을 배울 시간 없이 말을 인식해 자막만 빠르게 붙입니다.",
      "keywords": ["자막", "자동 자막", "캡컷"],
      "prepare": ["편집할 원본 영상", "브랜드명·제품명 목록"],
      "steps": [
        { "title": "1단계 — 원본 올리기", "lines": ["편집 도구에 원본을 올립니다.", "자동 자막 기능을 켭니다."] }
      ],
      "example": "이 영상의 말을 인식해서 자막을 넣어줘. 자막은 화면 아래쪽, 한 줄에 15자 이내로.",
      "prompts": [
        { "name": "말 인식해서 자막 넣기", "text": "이 영상의 말을 인식해서 원본 흐름을 유지한 채 자막을 넣어줘." }
      ],
      "trouble": [
        { "q": "고유명사가 틀려요", "a": "틀린 단어 목록을 미리 만들어 두고 마지막에 검색해 바꿉니다." }
      ],
      "note": { "type": "info", "title": "알아 둘 점", "text": "고유명사는 마지막에 직접 확인하세요." }
    }
  ]
}
```

| 키 | 설명 |
| --- | --- |
| `id` | 주소에 쓰이는 고유 이름. 영문 소문자와 `-`만. 7개 파일 전체에서 겹치면 안 됩니다. |
| `cat` | 카테고리 id. 파일의 `category.id`와 같아야 합니다. |
| `filter` | 그 카테고리의 `filters` 중 하나 (상황별 칩). |
| `title` | 카드에 보이는 쉬운 한국어 제목 (영어 기능 이름은 쓰지 않습니다) |
| `situation` | 카드를 열었을 때 제목 아래 나오는 한 줄 |
| `summary` | 카드에 보이는 2줄 요약 (35~42자 정도가 가장 깔끔합니다) |
| `keywords` | 검색에만 쓰이는 낱말. 화면에는 나오지 않습니다 |
| `prepare` | (선택) 모달 맨 위 **준비물** 목록 |
| `steps` | 따라 할 순서. `title`을 비우면 `lines`의 각 줄이 1·2·3 번호로 나옵니다 |
| `example` | (선택) **실제 입력 예시** — 그대로 복사해도 되는 예시 문장 |
| `prompts` | 복사 버튼이 붙는 명령어 상자. `name`은 상자 위 제목, `text`는 실제 복사되는 문장 |
| `trouble` | (선택) **자주 막히는 부분** — `q`(증상) / `a`(해결) |
| `note` | (선택) 맨 아래 안내 상자. `type`은 `tip` · `warning` · `info` |

`prompts`의 `text` 안에서 줄을 바꾸려면 `\n`을 씁니다. 쌍따옴표(`"`)는 `\"`로 적습니다.

## 카테고리를 새로 추가하려면

1. `data/새이름.json`을 위 양식대로 만듭니다. (`category.id` = `새이름`)
2. `data/categories.json`의 `categories` 배열에 한 줄을 더합니다.
   ```json
   { "id": "새이름", "emoji": "🧩", "title": "긴 제목", "nav": "탭에 보일 짧은 이름",
     "desc": "한 줄 소개", "file": "data/새이름.json", "itemCount": 0, "promptCount": 0 }
   ```
3. 탭은 배열 순서대로 생깁니다. 색은 `styles.css`의 `--cat-*` 값 중 하나를 쓰거나 기본 회색으로 둡니다.

## 로컬에서 확인하기

`data/*.json`을 읽어 오는 구조라 파일을 더블클릭하면 동작하지 않습니다. 폴더에서 아래를 실행하세요.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
# 카테고리 링크 시험: http://localhost:8000/?cat=design&only=1
```

`main` 브랜치에 올리면 GitHub Pages(`main` / 루트)가 자동으로 다시 빌드합니다. 1~2분 뒤 주소를 새로 고침하면 반영됩니다.

## 내용 규칙 (수강생에게 그대로 보이는 페이지입니다)

- 개인·타사 정보를 넣지 않습니다: `@`, 회사·브랜드명, 개인 블로그·채널 이름, 남의 채널 링크, 원문 출처 링크.
- 제목에는 영어 스킬 이름을 쓰지 않습니다. 실제로 붙여넣어야 하는 이름만 회색 명령어 칸 안에 둡니다.
- 초등학생도 이해하는 쉬운 한국어로 씁니다.
- 모든 숫자·명령어는 원본 노션 7개 페이지(`notion/ai-skill-hub/v2/01-video.md` ~ `07-ai-team.md`)와 대조합니다.
